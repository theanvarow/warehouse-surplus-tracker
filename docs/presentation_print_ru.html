1. Вход в систему и смена

Авторизация по QR-бейджу и столу

Каждая операция на складе строго привязана к конкретному сотруднику и рабочей станции:

🪪 Сканирование QR-бейджа
ФИО определяется исключительно по QR-коду сотрудника (ручной ввод с клавиатуры отключен во избежание фальсификаций).
🪑 Штрих-код рабочего стола
Сканируется код стола (STOL-01...STOL-20) и выбирается номер рабочей смены (1–4).
⏰ Авто-закрытие смен в 09:00 и 21:00
Автоматический выход из системы по окончании смены для фиксации итоговых отчетов.

4. Классификация расхождений

9 стандартизированных причин

Модальное окно выбора причины появляется автоматически при сканировании баркода:

📋 Регламентные причины:
1. Лишний товар в коробе (излишек)
2. QR / IMEI (не читается или поврежден)
3. Товар без акта (нет документов)
4. Ранее отменен (отмена до поступления)
5. Неверный товар / Пустая упаковка
6. Недокомплект (неполный набор)
🎯 Точная статистика
